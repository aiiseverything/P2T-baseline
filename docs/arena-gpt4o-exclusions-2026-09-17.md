# GPT-4o Arena-Hard 全量判分与失败排除

用户已明确要求继续全量判分，遇到裁判未按要求给出结论的 case 先保留失败记录，最终成绩可以排除这些 case。

本次使用 `gpt-4o` 裁判和官方 `gpt-4o-mini-2024-07-18` reference，复用六个候选模型的同一批3000条回答。每模型500题、两个顺序，共6000个game；不重新生成模型回答，也不改裁判提示词、temperature0、max_tokens16000或胜负解析规则。

## 新规则

- 新请求正常完成，但没有有效胜负标签，或裁判输出因长度上限截断：保留原文、usage、失败原因，继续后续请求，不再重复请求该game。
- 原有59个有效game、1个失败game及18份历史重试记录均保留并复用；不为了统一重试次数重跑付费请求。旧pilot用过最多5次同请求重试，新请求采用一次格式判分，因此历史重试策略差异会保留在记录中。
- 一个模型在某题的任一顺序失败，该模型该题的两个顺序一起退出计分。已成功的另一顺序仍保留原始记录，但不会单边计入胜率。
- 输出各模型按其有效题目计算的成绩；另输出六模型有效题目交集上的成绩。分别报告有效题数、失败game数、排除题数，以及因配对失败而不参与计分的有效game数。
- 未请求的game、网络传输状态不明、身份/请求/usage记录损坏不能作为裁判格式失败排除；这些状态会阻止实验被标记为完整完成。
- 沿用官方decisive权重3、tie值0.5及raw/style bootstrap数学。评分对象是有效子集，结果明确标记为自定义裁判且排除失败的实验。

排除题目可能不是随机样本；不同模型的有效题目也可能不同。共同子集表用于检查这种差异，不等同于完整500题的官方榜单成绩。
